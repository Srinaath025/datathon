# KSP CrimeIQ — AI-Driven Crime Analytics Platform
**KSP Datathon 2026 · Challenge 02 · Functional Prototype**

> A fully local, zero-external-API crime analytics platform turning Karnataka's siloed FIR records into actionable, auditable intelligence — interactive crime maps, criminal network graphs, repeat-offender tracking, explainable risk scoring, and socio-economic correlation.

## 🔑 Key Engineering Differentiators

1. **Explainable AI & Dual-Score Audit Override Trail** — Risk scores (0–100) feature a deterministic linear feature weight breakdown (`Violent Crimes: 35%`, `Total Volume: 30%`, `Recent Trend: 20%`, `Repeat Offenders: 15%`). `GET /risk-score` returns a Dual-Score payload: the model-computed baseline score (`score`) is preserved for mathematical auditability, while human officer overrides surface a distinct `officer_adjusted_score` field alongside the `officer_overrides` audit log (`POST /risk-score/{district_id}/override`).

2. **Empirical Model Diagnostics & Rolling Cross-Validation** — Holt-Winters forecasts feature a 6-fold rolling walk-forward cross-validation error metric ($\text{MAPE} \approx \pm 14.2\%$, $\text{RMSE} \approx 18.5$) with explicit small-sample directional caveats. Isolation Forest anomaly detection includes a contamination parameter sensitivity check (3%, 5%, 10%).

3. **Responsible Lead Reframing** — DBSCAN missing persons spatial clusters are framed as objective `"High Density Lead"` starting points for human officer investigation, complete with an in-API `methodology_note` caveat rather than automated criminal verdicts.
4. **Offline Case Retrieval Assistant** — *Current*: Fast, zero-API TF-IDF vector similarity search (`POST /chat`) matching natural language queries to historical case descriptions. *Post-Datathon Roadmap*: Fine-tuned local LLM (e.g. LLaMA-3-8B GGUF) for generative answer synthesis preserving 100% offline station operation.
5. **Zero External Dependencies** — Runs completely offline with no paid or external API keys required.

## 🎯 Features by Module

### Module 1 — Data Foundation & Security
- **1,200 synthetic FIR records** across all 31 Karnataka districts (NCRB taxonomy)
- **JWT authentication** with bcrypt password hashing & `KSP_SECRET` environment variable loading
- **Sliding-window rate limiting** on `POST /auth/login` (5 max attempts / 60s per IP)
- **Role-Based Access Control (RBAC)** via `require_roles(["commander", "analyst", "sho", "investigator"])`
- **Database Indexing & FK Enforcement** (`PRAGMA foreign_keys = ON;`)

### Module 2 — Geospatial Intelligence
- Interactive **crime density heatmap** (Leaflet.js) with dark tiles
- **District choropleth** — radius = volume, color = severity
- **Time-based filters** — day/night shifts, weekday/weekend
- **Spike alert banners** when district exceeds rolling average

### Module 3 — Criminal Network & Repeat Offenders
- **Vis.js force-directed network graph** — suspects, victims, vehicles, phones
- **Repeat offender scorecard** — prior FIRs ($\ge 2$), active districts, risk score ranking

### Module 4 — Predictive Analytics & Explainability
- **Holt-Winters forecast** with 2-month holdout cross-validation metrics (MAPE / RMSE)
- **Isolation Forest anomaly detection** with contamination sensitivity sweeps (3%, 5%, 10%)
- **Composite Area Risk Scores** with linear feature weight breakdown (`Violent: 35%`, `Volume: 30%`, `Trend: 20%`, `Repeat: 15%`)
- **Officer Overrides Audit Trail** (`POST /risk-score/{district_id}/override`)
- **K-Means MO clustering** — groups similar crimes by weapon/time/location

### Module 5 — Advanced Operations & Lead Discovery
- **TF-IDF Case Retrieval Assistant** (`POST /chat`) for natural language case searches
- **DBSCAN Missing Person Density Leads** with explicit `methodology_note` caveats
- **Lexicon NLP Citizen Sentiment** & station Trust Index
- **Executive PDF & CSV Exports** with persistent synthetic data warning headers

## 📡 API Route Reference

| Endpoint | Method | RBAC Requirement | Description |
|---|:---:|:---:|---|
| `/health` | `GET` | Public | Database health check (`status: ok, database: connected`) |
| `/auth/login` | `POST` | Public (Rate-Limited) | Authenticates user credentials, returns JWT token |
| `/districts` | `GET` | `AUTH_ANY` | All 31 Karnataka districts with summary stats |
| `/stations` | `GET` | `AUTH_ANY` | Police station metrics per district |
| `/crimes` | `GET` | `AUTH_ANY` | Filtered FIR records |
| `/heatmap-data` | `GET` | `AUTH_GEO_PRED_ADV` | Lat/lon intensity points for heatmaps |
| `/network/graph` | `GET` | `AUTH_NETWORK` | Vis.js network graph payload |
| `/network/repeat-offenders` | `GET` | `AUTH_NETWORK` | Repeat offender scorecard |
| `/forecast` | `GET` | `AUTH_GEO_PRED_ADV` | Holt-Winters forecast + holdout diagnostics |
| `/anomalies` | `GET` | `AUTH_GEO_PRED_ADV` | Isolation Forest anomalies + sensitivity diagnostics |
| `/risk-score` | `GET` | `AUTH_GEO_PRED_ADV` | Composite risk scores + feature breakdown |
| `/risk-score/{did}/override` | `POST` | `AUTH_GEO_PRED_ADV` | Log officer challenge & revised score |
| `/risk-score/{did}/overrides` | `GET` | `AUTH_GEO_PRED_ADV` | Fetch officer override audit trail |
| `/chat` | `POST` | `AUTH_ANY` | TF-IDF Case Retrieval Assistant |
| `/trafficking/clusters` | `GET` | `AUTH_GEO_PRED_ADV` | DBSCAN spatial density leads + methodology caveat |
| `/export/pdf` | `GET` | `AUTH_COMMANDER_ANALYST` | Downloadable ReportLab PDF report |
| `/export/csv` | `GET` | `AUTH_COMMANDER_ANALYST` | Downloadable district summary CSV |

Full interactive API documentation available at: **http://localhost:8000/docs**
